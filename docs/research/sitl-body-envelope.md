# x500_depth 的 SDF 碰撞体包络标定

日期：2026-10-26。结果来自本机 `drone-simulation` checkout 的真实 SDF；没有修改外部模型、起飞柱体、测量协方差或运动限值，没有启动 Gazebo/飞控。

运行：

```bash
PYTHONDONTWRITEBYTECODE=1 /usr/bin/python3 \
  validation/model/body_envelope.py \
  --tilt-rad 0.35 \
  --check-profile src/px4_powerplant_mission/config/p2_simulation.yaml \
  --report validation/evidence/sitl_body_envelope.json
```

脚本使用 `SDF_PATH` 指向原始模型目录，调用 `gz sdf -p` 让 libsdformat 展开 merge includes；自行解析展开后的 relative_to 图，将碰撞体转换到未放置的 **x500_depth 模型原点**。该原点是当前保留 SITL 配置的 PX4 导航参考，不是高出 0.24 m 的实体 base_link。四个输入 SDF 和展开结果的 SHA256 保存在 JSON 中；模型变动后必须重新运行。

## 解析界，而非离散姿态采样

姿态条件是机体总倾角 `tilt ≤ 0.35 rad`（约 20.05°），偏航任意。对固定碰撞盒的每个真实角点，令其在模型坐标中的高度为 `z`、水平半径为 `r`。其世界竖直极值由以下一维函数在 `0 ≤ θ ≤ 0.35` 的端点及驻点求得：

`z_min = min(z cosθ − r sinθ)`，`z_max = max(z cosθ + r sinθ)`。

完整盒体的竖直极值和水平半径上界由顶点取得：高度是线性函数，水平范数为凸函数。脚本也计算旋转后水平半径，使用点范数不变性及竖直区间距离零的最小值。

四个旋翼绕竖直关节轴连续旋转，**未锁定为 SDF 中某个初始 yaw**。对于每个角点，以关节原点水平半径加角点的关节轨道半径，包住该角点的所有旋翼 yaw；竖直坐标保持不变，再应用完整机体倾角锥。故脚本的解析结果同时覆盖任意旋翼角度和任意整机偏航。

不认识的碰撞形状、非竖直活动关节、活动关节后代、未展开模型、姿态图未解析或循环都会失败，不会跳过后给出局部“通过”。当前模型共有 **10 个 box 碰撞体、4 个旋翼完整 yaw 扫掠**。

总体解析界：

```text
z_min ≥ -0.05201653883447344 m
z_max ≤  0.41454883895579475 m
r_xy  ≤  0.46556035274093704 m
```

因此，SITL 配置采用 `body_radius_m=0.5`、`body_z_min_m=-0.06`、`body_z_max_m=0.5` 仍完整覆盖所有这些碰撞实体；在最紧的下界仍保留约 **7.98 mm** 额外几何余量。原先 `-0.1 m` 是更松的包络，不能误认为 SDF 本身确实向下伸到该高度。本次依据完整模型收紧到 `-0.06 m`，不是缩小实际模拟机体，不改变定位、跟踪、地图、反应时延或制动余量。

## 适用边界

- 这是 **当前 SDF 碰撞模型** 的几何标定。渲染 mesh 不是额外碰撞体；没有碰撞几何的 mapping_lidar_link 也不会被虚构成物理外壳。它不证明真实雷达外壳、载荷、线缆或真实无人机尺寸，硬件必须独立测量。
- 该结论依赖总倾角不超过 0.35 rad；不能把它理解为 roll、pitch 各自都可到 0.35 rad 后再叠加。增加倾角、修改支架或载荷后须重新计算。
- 几何计算不证明飞控跟踪误差、角运动响应、制动或接地动力学，也不构成完整 SITL 飞行验收。新的整机与状态不确定度停止盒仍须由现有执行器每周期完整检查，失败仍拒绝飞行。
- 没有扩大起飞柱体下缘，没有向地图加入伪造空闲，没有忽略真实占据。若标定后包络仍不成立，继续报告未通过；不能把 landed 标志当作地面高度/法向或把所有下降可达状态直接裁到地面。
