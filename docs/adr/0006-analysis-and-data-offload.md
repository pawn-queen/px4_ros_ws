# ADR-0006：分析与数据存储迁往 HP 工作站（推荐性约定）

- 状态：Accepted（**推荐性约定**，随项目阶段可调整；调整时更新本文件）
- 日期：2026-11-27
- 关联：[ADR-0003](0003-artifact-placement.md)、[SLAM 计划](../design/slam-plan.md)、[validation/README](../../validation/README.md)

## 背景

2026-11-25 的单次 SLAM 采集写入 10 GB MCAP，承载 WSL 虚拟磁盘的 D:（100 GB）被写满，ext4 转只读、进程收到 SIGBUS，整栈崩溃。仓库本体只有 13 MB、316 个文件，18 GB 日志与 5.3 GB `.venv` 全部位于被忽略目录。同一台开发机同时承担编码、构建、仿真、分析与存储，职责过载，且录制速率（原生 1920×1080 彩色 + 640×480 深度）决定了单个航次可达 10–25 GB。

现有远端资源：

| 节点 | 角色 | 已核实事实 |
|---|---|---|
| `gh-runner` | GitHub CI/CD | 由 GitHub Actions 使用 |
| `duoxuanyi@duoxuanyi-hp-proone-440-23-8-inch-g9-all-in-one-desktop-pc` | 构建、仿真、分析、存储 | Ubuntu 24.04.5（原生，非 WSL），20 核 / 15 GB，`/home` 103 GB 可用，ROS 2 Jazzy + `gz` 就绪，**无 NVIDIA GPU** |

## 决策（推荐性）

1. **职责分工**：本机负责编码与初步测试（单测、静态检查、构建、起栈到 `capture --prepare-only`）；HP 负责构建、仿真、完整航次、离线分析与数据存储；`gh-runner` 只承担 GitHub CI。完整航次不在本机执行。
2. **代码同步**：以 GitHub 为唯一真源，两机都通过 git 推送/拉取与 PR 流程同步；只有 `log/` 等忽略目录用 `rsync`。任何一方不得用 `rsync` 覆盖对方的工作区。
3. **数据落盘**：HP 上的每次采集放 `~/slam_data/<capture_id>/`，包含 `raw/`、`manifest.json`、`SHA256SUMS`、`report.*`；路径与哈希写进本机 `manifest.json` 的归档指针。
4. **本机最小证据集**：`report.json`/`report.md`、`frozen.json`、`manifest.json`、sha256 清单、`events.json` 与少量 status 采样。原始数据在远端 `sha256sum -c` 通过后可删。
5. **保留策略**：HP 保留全部原始数据；累计超过 300 GB 或单次采集超过 90 天时压缩归档（推荐值，可按磁盘调整）。本机保留**最近一次完整航次**的原始数据作为回退，其余在远端校验通过后删除。
6. **删除前置条件**：满足其一才可删——(a) 可由已提交代码与固定输入重建；(b) 已归档到远端且校验通过；(c) 已被 tracked 文档引用时，还必须先更新文档中的路径。
7. **可复现三件套**：远端分析报告必须记录 git commit、软件版本（RTAB-Map/ROS/Python 包）与数据 sha256，写在报告头或伴随 JSON 中。
8. **角色可调整**：本 ADR 描述当前阶段的分工，不构成永久约束。若后续 HP 增加 GPU、本机磁盘扩容或 CI 策略变化，直接修订本文件，不要新增"平行规则"文档。

## 取舍与验证边界

- HP 无 NVIDIA GPU，渲染路径与帧率尚未实测；在实测完成前，不得假定 HP 的相机/深度频率与本机一致（本机实测 5–6 Hz，已低于标称 30 Hz）。
- 远端未连通或校验未通过时，任何不可再生数据（原始 MCAP、`issue3_*` 证据目录）都不得删除。
- HP 上的工作区在与本机同步前保留其自身分支与未提交改动；同步顺序由 Issue #3 收尾进度决定，不得强制覆盖。
- 压缩格式以远端可解为准（当前本机有 `xz`、HP 有 `zstd`），压缩后必须校验解压流的 sha256 与原文件一致才能删除原件。
- 本 ADR 不替代 [ADR-0003](0003-artifact-placement.md) 的资产放置规则；两者冲突时以本 ADR 的数据迁移条款为准，其余仍按 ADR-0003。

## 可调整项

保留份数、压缩阈值、HP 数据目录、是否引入第三处备份——这些是运维参数，变更时只需更新本文件与相关脚本注释，不需要新的 ADR。
