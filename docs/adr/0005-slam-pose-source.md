# ADR-0005：SLAM 作为独立位姿源，UWB 分约束与校验两种角色

- 状态：第一阶段 Accepted。第二阶段的飞控集成、锚点角色与门控设计为 Proposed。
- 日期：2026-11-25
- 关联：[SLAM 引入计划](../design/slam-plan.md)、[ADR-0001](0001-runtime-validation-seam.md)、[ADR-0002](0002-mission-contract.md)、[定位部署](../../src/px4_powerplant_mission/LOCALIZATION_DEPLOYMENT.md)

## 背景

当前定位链路是"绝对定位 + 外部消费"：UWB 测距解算得到绝对位置，经 EV 桥进入 PX4 EKF；`localization_node` 默认以 `navigation_mode=px4` 转出 EKF 状态作为导航里程计；voxel mapper 单向消费该位姿建图。系统没有自运动估计，也没有"地图反过来约束位姿"的通道；UWB 失效时只有方差升高与停止发布，没有递推兜底。

目标是在 UWB 退化、短时失效或锚点几何变差时仍提供连续位姿，并让"SLAM"这一能力有可核查的实现与验收边界，而不是只换一个称呼。

## 决策

1. **第一阶段验证独立 SLAM。** 在已有 powerplant / gz_x500_depth SITL 中，RTAB-Map 用 OakD-Lite 彩色图、配准深度与独立滤波的机身 IMU，计算局部里程计、视觉回环和优化后的关键帧地图。正式试验在线与回放均验证真实重访、遮挡后重定位和视野外历史表面修正。保留 360° 雷达。UWB/PX4 负责试验飞行，Gazebo 真值只进入验证侧。
2. **第二阶段拟采用路线 1。** SLAM 位姿经 EV 桥进入 PX4 EKF，`localization_node` 继续以 `navigation_mode=px4` 输出导航里程计。`map` 帧保持等于 PX4 本地 ENU，不新增帧对齐层。直连导航（路线 2）留作后续优化，需单独 ADR。
3. **第二阶段的位姿出口只有一个。** `localization_node` 内的仲裁器按健康度在 `px4 | uwb | slam` 之间选择单一来源，带切换迟滞，切换时递增 `localization_epoch`。仲裁不是融合；多源加权会重新引入 `adaptive` 模式的相关性问题。
4. **第二阶段的 UWB 分两种角色。** 约束锚点进入估计器因子图，校验锚点只做残差监控且不进估计器。同一测量不得同时承担两种角色；最终精度验收必须使用独立参考（仿真真值或全站仪），不得用约束源自证。
5. **选型分三步。** RTAB-Map 先打通链路（BSD-3、官方 ROS 2 Jazzy 支持）；ORB-SLAM3 提供精度基线（GPLv3，分发方式需评估）；VINS-Fusion 只借鉴 GPS 因子结构与在线时空标定方法，不直接移植。
6. **第一阶段的历史几何属于 SLAM 关键帧地图。** 用优化后的位姿重新投影同一组历史观测，可独立验收地图修正。第二阶段中， voxel mapper 保持唯一供规划使用的占据地图。SLAM 的回环或跨图合并只修正它自己的轨迹，不同步修正该地图；因此位姿跳变或合并时必须递增 `localization_epoch` 并 bump `map_epoch`，旧地图作废重建。
7. **第二阶段拟将契约升级到 v2。** `localization_status` 增加位姿源、SLAM 追踪状态、回环计数、位姿跳变与地图纪元字段；Python、C++、JSON 三处镜像同改。`has_independent_position` 的语义明确为"独立于 PX4"，而不是"独立于一切来源"。

## 取舍与验证边界

- 独立 SITL 的判据与实机集成分别验收。只有原生档标定、独立在线盲验与三次回放有逐项证据时，才能宣称对应 SITL 能力。实机能力单独报告。
- 路线 1 以 EKF 平滑为代价换取帧一致性；它会把回环跳变在控制侧表现为缓变，同样也会掩盖短时失效，因此必须靠 `localization_epoch`、门控与审计字段显式暴露，不能依赖控制侧"看起来平稳"。
- 第一阶段的 `slam_map`、`slam_odom`、`slam_body` 在独立 TF 话题发布。任务系统沿用原有 `map → base_link`，第二阶段集成前需确定两者的对齐和切源语义。
- UWB 校验通道只能发现"与 UWB 不一致"，无法区分 SLAM 漂移与 UWB 自身故障。在线阈值必须与离线独立参考的结论联合解读。
- 2D 雷达在倾斜、变高飞行下匹配退化，只作为局部约束，不得据此声称回环能力。
- GPLv3 组件的分发合规需在选型阶段确认；进程隔离不等于自动合规。
- 多线程 SLAM 结果非确定，验收采用多次运行统计区间，不接受单次数值比对。
- 深度相机在强光、反光金属与超出有效距离时失效，属已知限制，不通过调参掩盖。

## 未决项

第二阶段仍需确定约束/校验锚点分组、2D 雷达的估计器收益、长期算法和实机资源预算。已确定的目标平台为 Orin NX 8GB、RealSense D435if、CUAV X7+ Pro 与二维 360° 雷达，UWB 锚点由开发板组成。用户给出的约 10 cm 精度只作实机背景。见[计划第 9 节](../design/slam-plan.md#9-需要拍板的未决问题)。
